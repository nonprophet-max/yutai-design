NAME

Company: Yutai Technologies, Inc.

FILES

png/  Transparent PNGs (seal 1024 px, lockups 1000 to 1600 px wide).

  yutai-lockup-horizontal-*   Primary logo

  ink     = one colour #030817, for light backgrounds and print
